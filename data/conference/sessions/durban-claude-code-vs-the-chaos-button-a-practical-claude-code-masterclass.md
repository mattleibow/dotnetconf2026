# Claude Code vs the Chaos Button - A practical Claude Code masterclass

What happens when you give Claude Code a broken application and ask it to fix it? A lot depends on your setup.

In this practical Claude Code masterclass, we’ll explore how to build a powerful setup that supports the way you develop. We’ll get into `CLAUDE.md`, skills and hooks: what they do, how they work together, and how to configure them for your project. From giving Claude the context it needs to building in coding standards and automating recurring checks, we’ll show how to make your setup work harder for you.

To put it all into practice, we’ll let the audience choose what breaks from a set of prepared bugs, then compare two approaches: vibe coding and hoping the fix works, and tackling the same problem with a carefully configured development setup. We’ll inspect the code and test the fixes, because a confident explanation doesn’t mean the problem is solved.

Expect practical walkthroughs, a live debugging demo, and ideas for building a Claude Code setup you can take straight into your own projects. No prior Claude Code experience required.
