# The ladder for productive agents

Frontier LLMs keep getting better. But it seems not muich is being said about how to use agents productively. If you've recently switched on 'agent mode' but would like to escape the pain of manually doing QA on agent outputs all day. This talk is for you. If you're wondering how to encode your business processes as skills. Or have found agent quality of agent work lacking. I'll cover skills, planning and how to inject taste back in to the agent loop. More importantly, i'll show you how I turn your agents in to helpful tools for productive work.
