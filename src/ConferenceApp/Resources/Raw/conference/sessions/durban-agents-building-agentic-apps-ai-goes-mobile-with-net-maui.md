# Agents Building Agentic Apps: AI Goes Mobile with .NET MAUI

Use AI to build the app, then give the app that same AI.

In this demo-driven session, we’ll put agents on both sides of mobile development with .NET MAUI. First, see how GitHub Copilot, MAUI AI skills, and tools such as MAUI DevFlow and Ailoha help coding agents build, inspect, interact with, and debug a running app.

Then we’ll bring AI into the app itself. Using Microsoft.Extensions.AI and emerging tools from .NET MAUI Labs, we’ll connect an assistant to app services and real actions: finding information, navigating screens, and updating app state, with user approval where it matters.

Follow one mobile app through both halves: built with help from agents, and powered by AI that does more than chat.
