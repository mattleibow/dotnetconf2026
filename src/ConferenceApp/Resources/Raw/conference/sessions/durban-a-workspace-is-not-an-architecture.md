# A Workspace is not an Architecture

Creating a workspace is fast and easy but also one of the easiest to get wrong. Workspaces are simply boundaries around fabric artefacts and not an architecture. This session looks at the architectural design decisions around creating workspaces and covers identity, security, capacities, networking, governance, ownership, deployment, and lifecycle management. This talk is aimed at anyone using Microsoft Fabric (or Power BI), where we examine how these decisions come together to create a scalable, secure and governed Fabric platform.
