# Second Brain, Sharper Agent: Feeding Your .NET Knowledge to GitHub Copilot CLI

AI coding agents are only as good as the context you give them. GitHub Copilot CLI will happily write code for your .NET app, but not code that follows your architecture decisions, naming conventions, or the lessons your team learned the hard way. So you end up re-explaining the same things in every prompt.

In this session, I'll show how to turn an Obsidian vault into a shared knowledge base that Copilot CLI can actually use. We'll structure ADRs, coding standards, and domain notes so they work for both humans and agents, connect the vault through MCP, and put it to work on a real ASP.NET Core codebase, comparing the same tasks with and without vault context.

You'll leave with:

- A vault structure you can copy for your own team
- Techniques for writing notes that agents understand
- A workflow where your docs stay alive because your tools depend on them
